## 📋 Description du Projet

**Outil interactif de simulation et d'analyse pour la gestion de stocks et de distribution.**  
Ce projet permet aux gestionnaires logistiques d'optimiser leurs niveaux de stock, réduire les ruptures et améliorer la collaboration entre distributeurs.

### 🎯 Objectifs
- Analyser la distribution statistique des ventes
- Simuler une chaîne d'approvisionnement avec réapprovisionnement automatique
- Optimiser le réseau de distributeurs via des transferts entre sites
- Prédire les ventes futures par régression linéaire

---

## ✨ Fonctionnalités Principales

| Fonctionnalité | Description | Technologies |
|----------------|-------------|--------------|
| 📊 **Analyse Statistique** | Tests de normalité (Shapiro-Wilk), histogrammes, Q-Q plots | SciPy, Seaborn |
| 📈 **Simulation Simple** | Gestion de stock avec seuils d'alerte et réapprovisionnement | SimPy, Matplotlib |
| 🌐 **Simulation Réseau** | Transferts entre 10 distributeurs basés sur la distance géographique | Geopy, SimPy |
| 📉 **Prédiction des ventes** | Prévision sur 12 mois par régression linéaire | Scikit-learn |
